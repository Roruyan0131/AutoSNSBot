# AutoSNSBot
AIでキャラクター画像を自動分類し、フォルダ整理からXへの投稿までを完全自動化するPythonシステム


---

## 想定される用途

- AIイラストの大量投稿の自動化
- イラストレーター・VTuberのSNS運用省力化
- キャラクター別コンテンツ管理
- 投稿業務のRPA化

---

## 技術スタック

- Python
- PyTorch
- torchvision
- Selenium
- pandas
- Pillow

---

## 特徴

本システムは単なるスクリプトではなく、  
「画像認識 × 業務自動化（RPA）」を組み合わせた実運用向けワークフローです。

人が行っていた
「画像を選ぶ → 整理する → 投稿する → 管理する」
という一連の作業を、すべて自動で処理できます。
